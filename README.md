# 🏏 Cricket Data Analytics

A **Cricket Data Analytics Project** using **Python** and **Power BI**.  
The project performs **Exploratory Data Analysis (EDA)** on cricket datasets, classifies players into meaningful roles, and builds an **interactive Power BI Dashboard** with role-based insights, navigation, and performance metrics.  

---

## 🔍 Project Highlights
✔️ Performed **EDA** on cricket data for insights.  
✔️ Classified players into different roles:  
   - 🏏 **Power Hitters**  
   - 🛡️ **Anchors**  
   - 🎯 **Finishers**  
   - ⚖️ **All-rounders**  
   - 🎳 **Specialist Bowlers**  
✔️ Built an **interactive Power BI Dashboard** with:  
   - Role-based pages  
   - Button navigation  
   - Custom visuals  
   - DAX measures for performance insights
